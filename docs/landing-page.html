Why we built it

A post slider should not need a paid add-on

Elementor's own Posts and Loop Carousel widgets are part of Elementor Pro, and post sliders in add-on packs are often part of a paid tier.

If all you want is your latest articles in a neat row of cards, that is a lot to pay for. So we made a free Elementor slider for exactly that job, and kept adding the things people asked for: grids, related posts, product cards, more templates.

Today it is the carousel plugin Elementor users can set up in a minute. Drop the widget on a page, pick your posts, pick a template. Everything on this page is in the free plugin, because there is no other version.

How it works

From empty page to post slider in three steps

  1. 01

    Install the plugin

    In your dashboard go to Plugins, Add New, and search for “Post Carousel WebCodingPlace”. Elementor needs to be active.

  2. 02

    Drop in the widget

    Edit any page with Elementor, search for “Post Carousel” in the widget panel and drag it where you want it.

  3. 03

    Choose posts and a look

    Pick a source, a template and a layout. The preview updates as you go, so you publish when it looks right.

Carousel, grid or list

Carousel grid, post slider or simple list: one widget

Every widget has a Layout switch. Keep it as a sliding carousel, turn it into a grid that follows Elementor's tablet and phone breakpoints, or use the list layout with the image next to the text.

Some people call it a grid slider, some call it a carousel grid. Either way you set the columns for desktop, tablet and phone, and the plugin handles the rest. Grid and list layouts load no slider script at all, so they stay light.

What you can control

Every setting lives in the Elementor panel

No shortcodes, no separate settings screen. Click the widget and change what you need.

  • Related posts

    On a single post, show posts that share its categories, tags or any other taxonomy. It can fall back to your latest posts when nothing is related.

  • Archive and search pages

    Set the source to Current query and the widget shows the posts of the category, tag or search page it sits on.

  • Filters that make sense

    Include or leave out terms and authors, limit by date, skip the first few posts and decide what happens to sticky posts.

  • A Card you can shape

    Switch the image, category badge, meta row, excerpt and button on or off. New carousels start with this template.

  • Image ratio and hover

    Set the aspect ratio, fit and corner radius, then add a zoom, lift or darken effect. Works on all 52 templates.

  • Meta row

    Date, author, author picture, categories, comment count and reading time. Show only the ones you want.

  • Effects and pagination

    Slide, fade, coverflow or a centered active slide, with dots, numbers or a progress bar underneath.

  • News ticker

    A steady, continuous scroll for headlines. It stops when a visitor hovers over it or tabs into it with the keyboard.

  • Light on your pages

    Only the stylesheet of your template loads, about 6 KB. New carousels reuse the Swiper library already inside Elementor.

Updating from version 1.4?

Your existing carousels stay exactly as they are

Carousels made before 2.0 keep the Classic engine and look the same after the update. New carousels use the Modern engine, built on the Swiper library that comes with Elementor. You can switch any carousel with one setting, and switch back.

FAQ

Questions people ask

Something else on your mind? Ask in the support forum and we will help.

Is this carousel plugin for Elementor really free?

Yes. Every feature on this page is in the plugin on WordPress.org. There is no Pro version, no trial and no setting that asks you to upgrade.

Do I need Elementor Pro?

No. It works with the free Elementor plugin, version 3.18 or newer. If you have Elementor Pro, you can also use the widget in Theme Builder templates, for example for related posts on single posts.

Can I show a grid instead of a slider?

Yes. Set Layout to Grid or List and choose the number of columns for desktop, tablet and phone. Grid and list layouts load no slider script.

Can I make a WooCommerce product slider?

Yes. Set the post type to Products. You can limit it to featured, on sale, best selling or top rated products, and the Card template shows price, rating, a Sale badge and an Add to cart button.

I used version 1.4. Will my carousels change?

No. Carousels you made before keep the same template, settings and slider script. The one visible change is a fix: a default star icon in some templates was invisible and now shows.

Will it slow down my site?

The plugin loads nothing on pages without the widget. On pages with it, it loads a small base stylesheet and the one for your template. The Modern engine reuses the Swiper library that Elementor already has.

Can I change a template or add my own?

Yes. Copy a template file to a dpce folder in your theme and edit the copy, or register a new template with the dpce_styles filter. The developer guide on GitHub has examples.

Does the plugin collect any data?

No. It sends nothing from your site. The optional share buttons only contact a social network when a visitor clicks one.
